# Atomic iOS SwiftUI SDK

A SwiftUI framework for embedding Atomic stream containers in your iOS app.

For documentation, see [Atomic iOS SwiftUI SDK Guide](https://documentation.atomic.io/sdks/ios-swiftui).

## Requirements

- iOS 16.0 or later. This minimum applies to `AtomicSwiftUISDK` and to the `AtomicSDK` framework it depends on.
